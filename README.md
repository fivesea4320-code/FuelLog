# 내 차 연비 기록 (FuelLog v1.1)

한국어로 사용할 수 있는 **오프라인 안드로이드 휘발유 차량 주유 기록 앱**입니다.

## v1.1 화면 구성
- 첫 화면에 주유 날짜, 주행거리, 주유량, 금액(LAK), 가득 주유 체크가 함께 있습니다.
- **저장하고 연비 확인**을 누르면 같은 화면 바로 아래에 최근 2개월 km/L와 ₭/km가 갱신됩니다.
- 화면 하단의 주유 내역에서 이전 입력을 확인하고 CSV 내보내기가 가능합니다.

## 기능
- 주유 날짜, 계기판 누적 주행거리(km), 주유량(L), 주유 금액(라오스 킵, ₭), 가득/부분 주유 입력
- 최근 2개월 동안 **완료된 가득 주유 구간**만 합산해 실제 연비(km/L) 및 km당 비용(₭/km) 계산
- 중간 부분 주유 내역을 포함하여 합산 (최초 가득 주유 → 다음 가득 주유)
- 기기 내 SQLite 로컬 저장; 항목 길게 눌러 삭제
- CSV 내보내기 (Excel에서 열 수 있음)

## 연비 계산법 (중요)
1. 첫 가득 주유 시 **기준점**을 기록합니다. 이 주유량/금액은 이후 구간의 연료 소비량에 포함하지 않습니다.
2. 두 번째 가득 주유 시 두 시점의 누적 거리 차이를 구합니다.
3. 해당 구간의 소비 연료는 **첫 가득 주유 이후부터 두 번째 가득 주유까지 주유한 양의 합**으로 봅니다.
4. `km/L = 해당 구간 주행 거리 / 해당 구간 주유량`, `₭/km = 해당 구간 주유 금액 / 해당 구간 주행 거리`.
5. 두 달 합계는 완료일이 최근 2개월 이내인 구간의 주행거리, 주유량, 금액을 합산합니다. 따라서 구간 시작일은 두 달보다 이전일 수도 있습니다.

**주의**: 정확성을 위해 가득 주유 시마다 유사한 수준까지 채우세요. 단순히 일부만 주유한 뒤 현재 주행거리/주유량으로 바로 나누면 정확한 실연비가 되지 않습니다. 차량 연료탱크에서 새는 연료 등은 계산하지 않습니다.

## Android Studio에서 APK 만들기
1. Android Studio 설치 후 **Open**으로 이 폴더 `FuelLogAndroid`를 선택합니다.
2. 인터넷에 연결된 환경에서 Gradle 동기화를 완료합니다. JDK 17 이상 필요합니다.
3. 메뉴 **Build → Build Bundle(s) / APK(s) → Build APK(s)** 선택.
4. 생성된 `app/build/outputs/apk/debug/app-debug.apk` 파일을 안드로이드 폰으로 옮긴 후 설치합니다. (설치 권한 확인 필요)

이 프로젝트는 AGP 8.6.1 / compileSdk 35 / Java 17 기준입니다. Android 6 이상 기기를 대상으로 합니다.

## 구현 범위
- 화면과 CSV에 표시되는 금액은 **라오스 킵(₭ / LAK)** 기준입니다. 환율 변환은 하지 않습니다.
- 주행거리 기록은 증가하는 순서대로 추가합니다. 과거 기록 수정 대신 삭제 후 재입력이 필요할 수 있습니다.
- 앱 삭제 시 기기 내 기록이 제거될 수 있으니 CSV 백업을 권장합니다.

## GitHub Actions로 APK 만들기 (Android Studio 없이)
1. GitHub에 새 저장소를 만들고 **이 폴더 안의 파일들**을 저장소 최상위에 업로드합니다 (`.github` 숨김 폴더 포함).
2. 저장소의 **Actions → Build Android APK → Run workflow**를 누릅니다.
3. 빌드가 성공하면 실행 화면의 **Artifacts → FuelLog-debug-apk**에서 zip을 다운로드합니다.
4. 압축을 풀면 `app-debug.apk`가 있으며 안드로이드에서 설치할 수 있습니다.

참고: GitHub Actions 실행에 인터넷 및 GitHub 계정이 필요합니다. 이곳에서는 Android SDK/Gradle 빌드 환경이 없어 실제 APK 파일은 검증하지 못했습니다.
